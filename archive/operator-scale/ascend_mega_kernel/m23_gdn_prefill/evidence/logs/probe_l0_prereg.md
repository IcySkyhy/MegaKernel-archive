# 预登记（短）：最小 AIC 探针 —— L0A/L0B/L0C 的 16/17 tile 边界

**两轴**：tiles = 1（M=16，一个 16 行 tile）vs 2（M=17，两个 tile：16+1，第二个 pad 到 16）；
arm = A（**段体现用形态**：每个 tile 一次 BufferID 轮转 `BUF_L1→BUF_L0→BUF_L0C`，tile 之间**无额外屏障**）
vs B（**保守形态**：tile 之间加显式 `PipeBarrier<PIPE_M>` + `PipeBarrier<PIPE_MTE1>`）。

**预测与判据**（先写后跑）：
| 观测 | 判读 |
|---|---|
| **A 臂挂、B 臂不挂** | 段体的同步形态本身是缺陷 ⇒ **软件问题**，不是硬件 |
| **A、B 两臂都挂** | 落在硬件/ISA 约束上（才配叫"硬件问题"） |
| 两臂都不挂 | 探针**没复现到触发条件**，如实说，不硬凑 |

**指纹判据**：不是"挂了"就算，而是 **`mte error info` 的低位是否仍是 `…0202ce`**（与 4097 档逐位比对）；**签名不同要如实区分**。

**规模**：先 **1 个 AIC**（`__global__ __cube__`、blockDim=1）；复现不了再上 mix(1,2) 满核。
**类型**：**fp32**（= 本段操作数类型；塔消息里的"bf16"与本段不符，按段体实际取 fp32）。
