# M=1 的重复性统计（人类指令：「m=1 的时候也是概率失败吗，你多跑几次」）

**预登记**：`evidence/logs/m1_repeat_prereg.md`（N、判据、措辞纪律、状态性检查项**先写后跑**）。
**命令模板（逐字；每次 run 一次独立 `flock`，`-w 300`、`timeout 25`、run 前记 `npu-smi`）**：
```
M15GP_ONLY_M=<m> timeout 25 flock -w 300 /tmp/npu0.lock stdbuf -oL ./build/m23_gdn_prefill \
    > evidence/logs/rep/rep_<tag>.log 2>&1; rc=$?
```
判据：FAIL = `rc!=0` 且含 `507015`；PASS = `rc==0` 且含 `ALL RUNS OK`；其余记 OTHER。
汇总（逐次原始行）在 `evidence/logs/rep/summary.txt`，每档逐次日志 `evidence/logs/rep/rep_*.log`。

## 计数 + 二项 95% CI（Wilson）+ 逐次序列
| 档 | N | FAIL | OTHER | 命中率 | 95% CI（Wilson） | 逐次序列（时间顺序） |
|---|---|---|---|---|---|---|
| M=1（主档） | 50 | 0 | 0 | 0.0% | [0.0%, 7.1%] | `PPPPPPPPPPPPPPPPPPPPPPPPPPPPPPPPPPPPPPPPPPPPPPPPPP` |
| M=24（对照锚点） | 20 | 3 | 0 | 15.0% | [5.2%, 36.0%] | `PPPPPPPPFPPFPPPFPPPP` |
| M=4097（对照锚点） | 10 | 10 | 0 | 100.0% | [72.2%, 100.0%] | `FFFFFFFFFF` |
| M=1（4097 之后，跨档残留探测） | 10 | 0 | 0 | 0.0% | [0.0%, 27.8%] | `PPPPPPPPPP` |

（`P`=PASS、`F`=FAIL、`O`=OTHER）

## 逐条回答
1. **M=1：50 次全部 PASS、0 次 FAIL** ⇒ 按预登记的措辞纪律，只能说
   「**在 50 次里未观察到失败（命中率上界约 6%，95% CI）**」，**不得**写"m=1 不会失败"。
2. **M=24：3/20 = 15% 命中** ⇒ **修正我上一轮的报告**：上一轮我只跑了 6 次 M=24（0/6）就倾向"小 M 不挂"，
   20 次采样后命中率 15% —— **样本太少时的 0/6 不足以支持"M≤24 不挂"**；这条我更正。
3. **M=4097：10/10 命中**（从未通过）⇒ 与"命中率随 M 上升"一致（大 M 近确定）。
4. **跨档残留**：M=4097 那批之后回到 M=1 再跑 10 次 ⇒ **10/10 PASS** ⇒ 未观察到"被 4097 批污染"。
5. **失败签名**：失败档的 `mte error info` 取值集合 = 0x13d10000000202c, 0x13d15000000202c, 0x13d24000000202c, 0x13d6f000000202c, 0x13d79000000202c, 0x13d7e000000202c；其**低位（去掉第 5 位核号字段后）** 均为
   `d10000000202c, d15000000202c, d24000000202c, d6f000000202c, d79000000202c, d7e000000202c` ⇒ 与 4097 档**同类**。
6. **状态性**：`F→下一次仍 F` 的条件计数 = 9 / 12（样本含 M=24 与 M=4097 的 F 次）。
   **限度**：本档的 `npu-smi` Health 字段**未能取到**（我的抽取格式与 `npu-smi` 实际输出列不匹配，采到空串）
   ⇒ 原样记成"未取到"，**不以它下任何结论**；每 run 的**设备错误报告**本身都在各 `rep_*.log` 里。
