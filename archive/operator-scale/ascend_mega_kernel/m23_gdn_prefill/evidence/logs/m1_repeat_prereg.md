# 预登记：M=1 的重复性统计（**先写后跑**）

## 为什么
人类问：「m=1 的时候也是概率失败吗，你多跑几次」。此前 M=1 只跑过 1 次（OK），**无统计意义**。

## 档位与 N（先定）
| 档 | N | 已知先验 |
|---|---|---|
| **M=1**（主档） | **50** | 此前 1/1 OK |
| M=24（对照锚点） | **20** | 此前 0/6 命中 |
| M=4097（对照锚点） | **10** | 此前 4/4 命中、从未通过 |

## 判据（先定）
* **FAIL** = `rc != 0` **且** stdout 含 `507015`；
* **PASS** = `rc == 0` **且** stdout 含 `ALL RUNS OK`；
* 两者都不是 ⇒ 记 `OTHER`（如实列出，不塞进上面两类）。

## 统计口径
* 报告**逐次序列**（按时间顺序，`P`/`F`/`O`）——**随机 / 成簇 / 交替是三种不同形态**，只报总数会丢掉它；
* 报**计数 + 二项 95% 置信区间**；**措辞纪律**：若 50 次全 PASS，只能写
  "**在 50 次里未观察到失败（命中率上界约 6%，95% CI）**"，**不得**写"m=1 不会失败"；
* 每次失败逐字留证：`rc`、`mte error info`（逐核）、`multi-bit ECC`/`timeout or trap` 行数，
  并与 4097 档签名**逐位比对**。

## 状态性检查（本轮重点）
* **每次 run 之前**记录 `npu-smi` 的 Health 与有无残留进程；
* 检查"**前一次 FAIL 是否影响下一次**"（按序列看配对 `F→?` 的条件成功率）；
* 检查**跨档残留**：`M=4097` 那批跑完后回到 `M=1` 的尾部几轮（本节 M=1 在 4097 之前，故改为
  **顺序 = M=1(50) → M=24(20) → M=4097(10)，并在 M=4097 之后追加 M=1 的 10 次**做"跨档残留"探测）。

## 命令模板（逐字；**每次 run 一次独立进锁**）
```
M15GP_ONLY_M=<m> timeout 25 flock -w 300 /tmp/npu0.lock stdbuf -oL ./build/m23_gdn_prefill \
    > evidence/logs/rep_M<m>_i<i>.log 2>&1; rc=$?
```
同二进制、同一开关路径（`M15GP_ONLY_M`）；**不设开关时默认行为逐字不变**（未改该路径）。
