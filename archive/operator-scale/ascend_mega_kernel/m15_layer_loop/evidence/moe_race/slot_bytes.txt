## 读法（逐条）
1. **修后（c9_fix_dump / c9_fix_mldump）**：槽 = `00000000`，同层 x_norm 行 0 的 [2176:2180] 是各层
   自己的残值（非零、逐层不同）⇒ **槽不再是残值**；判据 48/48 PASS ⇒ **两侧都是这个 0**（= 本档 badIds）。
2. **未修 · 融合路读到残值（c9_unf_dump L00、mn_unf_dump L00/L01）**：槽 == 残值，且判据 PASS
   ⇒ 两条路径**都**读到残值 ⇒ 这条 PASS 与计数器无关（假绿）。
3. **未修 · 融合路读到计数器（c9_unf_mldump）**：槽 = `00000000`，而判据 36 条 FAIL 且 `exp 0x??`
   **逐层等于**该层 x_norm 行 0 的 [2176] ⇒ moe-only 侧读到的是残值。9 层逐层对上（见下）。
4. **拨值探针**：把写进槽的值改成 `oobCountUb ^ 0x5A5A5A5A`（仅 /tmp）—— 修后槽 = `5a5a5a5a`（值随写落盘，
   **不是**残值）；同一改动在未修档槽 = 残值（`593f36bc`/`8c3f07bd`），`5a5a5a5a` 根本没落地 ⇒ 那 4 B 在未修档
   与这次标量写**无关**，修后才有关。

## 9 层逐层对照（未修档 `c9_unf_mldump`：`exp` 首字节 vs 该层 dump 的 x_norm[2176]）
```
   层       融合路槽首字节(got)    moe-only侧首字节(exp)    同层 x_norm[2176]    对上?
  00                 00                   59                 59      是
  01                 00                   8c                 8c      是
  02                 00                   9b                 9b      是
  04                 00                   c8                 c8      是
  05                 00                   68                 68      是
  06                 00                   89                 89      是
  08                 00                   a1                 a1      是
  10                 00                   cd                 cd      是
  14                 00                   d0                 d0      是
```
（`got` 那列 9 层都是 `00` ⇒ 融合路这次读到的是计数器；`exp` 与同层 x_norm[2176] 逐层相同 ⇒ moe-only 侧读到残值。）
