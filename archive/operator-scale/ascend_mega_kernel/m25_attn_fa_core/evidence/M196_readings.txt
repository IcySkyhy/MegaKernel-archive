3. 负向对照（任务 4）
--------------------------------------------------------------------------------
命令：先 m=1，再 m=4097（`M25FA_M=<档> M25FA_OUT=… timeout 120 <bin> <mode>`）。

表 3.1 —— `m=4097`（prefill）：三者 **FAIL**（判据会咬）
| mode | VERDICT | over / 总 | maxratio | out[0,0,:4] |
|------|---------|-----------|----------|-------------|
| negmask  | **FAIL** | 5307050 / 25171968 | 80.5583  | -0.015503 -0.015747 0.041016 0.002365 |
| negshift | **FAIL** | 4087447 / 25171968 | 208.5186 | -0.925781 -0.867188 -0.648438 -0.894531 |
| negstart | **FAIL** | 689610 / 25171968  | 134.5047 | 0.135742 -0.746094 -0.882812 -0.675781 |
（对照 `core`：`out[0,0,:4] = 0.851562 -0.636719 -0.867188 -0.648438 = V[0,0,:4]`，行 0 位置 0 只见 j=0。）

表 3.2 —— `m=1`（decode）：三者 **PASS（不咬）** —— 如实登记
| mode | VERDICT | over / 总 | maxratio | 与 core 的差异 |
|------|---------|-----------|----------|----------------|
| negmask  | PASS | 0 / 6144 | 0.3227 | 6144/6144 元素变，maxabs 2.2e-3 |
| negshift | PASS | 0 / 6144 | 0.5852 | 5961/6144 元素变，maxabs 3.4e-3 |
| negstart | PASS | 0 / 6144 | 0.0262 | 235/6144 元素变，maxabs 2.4e-4 |
机制（读数是这三条的支撑，不是猜测）：m=1 的单行 `posBase=4096` 已可见全部 4097 列 ⇒
因果掩码在该位置无实质作用（negmask 只引入 ~1e-3 级扰动）；`negshift` 把 K/V 整体挪 16 token，
而输出是 4097 项 softmax 平均，扰动被摊薄；`negstart` 的 `posBase+1=4097 ≥ ctx-1`，因果窗已到底。
三者扰动都落在**尺度型容差**（`tol = EPS·(Σp|v| + |ref|) + …`，`EPS=2^-9·4`）内 ⇒ 判据 PASS。
⇒ 负向对照的「咬」只在 prefill 档（能改变**短上下文行** m=4097 行 0）出现。
因此验收以 **§3.1 的 m=4097 三负控 FAIL** 作为「判据非永真」的证据；m=1 的读数在此如实登记。
