## 2. host dump 目录创建不再走 shell（P2-5 回归）

`m22_router512.asc` 的 host 侧原用 `snprintf(cmd,…,"mkdir -p %s",dir); system(cmd)`，
`M22_OUT` 含 shell 元字符时会被解释。现改为逐级 `mkdir(2)`（`MakeDirs()`，`<sys/stat.h>`）。

回归自测：

```bash
M22_OUT='/tmp/m22fix_x; touch /tmp/m22_pwned' ./m22_router512/build/m22_router512
```

| 观测 | 结果 |
|---|---|
| `/tmp/m22_pwned` 是否被创建 | **不存在**（旧写法会创建它） |
| 字面目录 `/tmp/m22fix_x; touch /tmp/m22_pwned` | **被创建**（元字符按字面处理） |
| 该次运行的判定 | judged 100/100，退出码 0 |

（`host` dump 是验收脚手架而非产品路径；此处按 review 建议 2 行修掉。）
