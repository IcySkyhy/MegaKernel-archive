8-layer residual double-GEMM — training the flipped identity

RTX 5070 Ti (sm120), cuBLAS fp32 reference + NVFP4 simulation. Top: raw MSE loss. Bottom: relPJ, the distance of the recovered linear map P to the true flip J — the honest, cross-run-comparable metric.

Reading it: L=1 (gray) solves instantly — one layer is enough. L=8 plain (red) stalls at loss ~2e-2 / relPJ ~0.15: the determinant-sign barrier. L=8 + homotopy (green) — ramping the target I→J — cracks it to loss ~4e-7 / relPJ 6e-4 (exact). +fp4 QAT (blue) trains the fast arch end-to-end in NVFP4: relPJ 0.13, the e2m1 noise floor (the flip itself is structurally perfect, b≈0.98).

Loss during a homotopy run is measured against its moving target (easy early, when the target ≈ identity), so the loss panel isn't directly comparable across runs mid-training — the relPJ panel always measures against the true flip and is the honest comparison.
