# sinter (reserved name, frozen)

**Empty on purpose.** This repo was created ahead of its substance: no
config-invariant method has been extracted into it yet. The persistent-decode
megakernel and its still-config-bound core live in the worked example,
[sinter-qwen36-nomtp-tu102](https://github.com/slartibardfast/sinter-qwen36-nomtp-tu102),
under `core/` and `k0/ops/`.

A skeleton earns its name only when a **second** instance is authored and
reveals what is genuinely config-invariant (you cannot factor a common core out
of one instance). Until then this is a reserved name, frozen, not a deliverable
and not evidence of a reusable method.

Provenance: yarn-agentic `plan/0139`. Unlicense (public domain).
